NEW IN V6
- Local device date/day indicator; current weekday is highlighted in the class timetable. The browser sends its local date, weekday, and time to the backend so the AI can start Day 1 today and avoid suggesting earlier times.
- Exam/assignment calendar, selected-date view, and countdowns (Due today / tomorrow / days remaining).
- Upcoming calendar entries are passed to the model when generating or refining plans.
- Smart rescheduler moves overdue, unchecked tasks into future slots. It respects valid saved class times, recognized existing study blocks, the daily study-time limit, and matching future deadlines in the exam calendar or dates explicitly written in the deadlines field (for example, `Mathematics internal — 22 Oct — Unit 1` or `Assignment — 2026-10-22`). It adds a small buffer between class/study blocks and checks up to 60 days ahead. Tasks that cannot all fit remain in the original plan instead of being silently removed.
- Full JSON backup and restore includes saved plans, completion progress, weekly timetable, exam calendar, active plan, and current form draft.
- Safer restore validation, malformed local-storage normalization, validation of stored dates/times, and stronger local API error messages.
- Duplicate Day N headings emitted by a small model are merged into one visual day card.

DATA / LIMITATIONS
Data saves in the current browser's localStorage. Use Backup & restore before clearing browser data or changing browsers. Restore replaces current data and asks for confirmation.
AI suggestions are not guaranteed to be perfect. The deterministic rescheduler prevents conflicts with valid times recorded in the class timetable, known clocked study blocks, and applicable future dates it can identify. It can recognize dates like `22 Oct`, `Oct 22`, `22/10/2026`, and `2026-10-22` in the deadlines field, but it cannot infer class times you have not entered or safely interpret ambiguous prose. Add important exams as calendar entries for the most reliable countdowns and scheduling.
No login page is included. AI inference stays local through Ollama; do not expose the local Express API to the public internet.
